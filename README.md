# Console Minesweeper

A C++ implementation of the classic Minesweeper puzzle, built as a Visual Studio console project.

## Overview

The project explores grid-based game logic, user input and game-state handling in a console environment. The objective of Minesweeper is to reveal safe cells while avoiding hidden mines.

## Concepts Demonstrated

- Two-dimensional grid modelling
- Console input and output
- Conditional logic and game-state transitions
- Win/loss conditions for a turn-based puzzle

## Technology

- **Language:** C++
- **IDE / build system:** Visual Studio
- **Solution:** `Minesweeper.sln`
- **Implementation:** `Minesweeper/Minesweeper.cpp`

## Run Locally

1. Install Visual Studio with the **Desktop development with C++** workload.
2. Clone the repository:
   ```bash
   git clone https://github.com/MihailKanev01/tu-varna-cpp-console-minesweeper.git
   ```
3. Open `Minesweeper.sln` in Visual Studio.
4. Build the solution and run the application.
